## What Package D delivers

Package D extends the accepted A/B/C deterministic career substrate with one authoritative world-model-4 source for player capability, development, role/scheme learning, opportunity, workload/readiness, medical truth, medical knowledge, and knowledge-safe decision evidence.

- Per-dimension capability development with bounded causal change, plateaus, zero change and decline; no universal OVR, XP meter or fixed-potential destiny field.
- Capability-family-specific aging rather than a universal age cliff.
- Finite opportunity pools, finite staff teaching bandwidth, explicit GM intent and staff/authority boundaries.
- Responsibility-level role and scheme learning; labels alone do not create skill.
- Deterministic/idempotent development checkpoints driven by logical sim time.
- Medical episode truth separated from organizational diagnosis/prognosis knowledge, with structural healing, function, conditioning, risk, limitation, preference, recommendation, clearance and usage able to disagree.
- Immutable historical development/medical evidence and player-movement continuity without rival private-state leakage or revenge boosts.
- Knowledge-safe development/acquisition decision views and opportunity-cost previews.
- Symmetric human/CPU legality plus development/medical exploit audits.
- An integrated persisted/replayed/recovered Package D golden and on-device direct + SQLite diagnostic.

## Cross-runtime note

The standalone prebuilt Hermes CLI used for the independent semantic gate is the official Facebook Hermes v0.13.0 Windows release asset, whose runtime reports OSS Hermes 0.12.0 / bytecode 96. That older CLI cannot parse the generated ES2015 class-expression syntax, so the bundle uses Babel `transform-classes` as a syntax-only lowering step. No simulation mismatch was normalized away. The resulting standalone-Hermes identity equals Node exactly, and the physical iPhone Expo Go run supplies the exact current React Native/Hermes device-runtime gate.
